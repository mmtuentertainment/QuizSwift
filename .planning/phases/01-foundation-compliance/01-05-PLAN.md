  <how-to-verify>
**Prerequisites:**
1. Ensure DATABASE_URL is configured and database is running
2. Run migrations: `npx prisma migrate dev`
3. Ensure Google OAuth credentials are configured (AUTH_GOOGLE_ID, AUTH_GOOGLE_SECRET)
4. Generate AUTH_SECRET: `openssl rand -base64 32`
5. Start the app: `npm run dev`

**Test AUTH-01: Google OAuth Sign-in**
1. Visit http://localhost:3000/dashboard
2. Should redirect to /login
3. Click "Sign in with Google"
4. Complete Google OAuth flow
5. Should redirect to /dashboard showing your name/email
6. PASS if: Dashboard shows "Welcome back!" with your email

**Test AUTH-04: Session Persistence**
1. While logged in, close the browser tab
2. Open a new tab and visit http://localhost:3000/dashboard
3. PASS if: Still logged in, dashboard shows without login prompt

**Test PLAT-02: Audit Logging**
1. Visit http://localhost:3000/admin/audit
2. Set date range to include today
3. Click "Search"
4. PASS if: You see audit log entries including your user creation (INSERT on User table)

**Test PLAT-03: DPA Template**
1. Visit http://localhost:3000/admin
2. Click "Download DPA Template"
3. PASS if: DPA template downloads with FERPA/COPPA sections

**Test PLAT-04: Data Deletion (optional - destructive)**
Note: This will delete your account. Only test if you want to verify deletion works.
1. Note your user ID from the audit logs
2. Use curl or API client:
   ```bash
   curl -X DELETE http://localhost:3000/api/admin/users/[YOUR_USER_ID]/delete \
     -H "Cookie: [YOUR_SESSION_COOKIE]"
   ```
3. PASS if: Returns success, you're logged out, audit shows ANONYMIZE action

**Test PLAT-01: COPPA Compliance**
1. Review the DPA template
2. PASS if: DPA includes school consent section for under-13 students
