## Deviations from Plan

### Bug Fixes Required

**1. Document page showing wrong data**
- **Issue:** Page checked legacy `Question` table, showed "No questions found"
- **Fix:** Added `curatedQuestions` query, conditional display based on pipeline type
- **Committed in:** 466feef

**2. Star rating RangeError**
- **Issue:** `String.repeat(-15)` error because score was 0-5, code assumed 0-1
- **Fix:** Changed `Math.round(score * 5)` to `Math.min(5, Math.max(0, Math.round(score)))`
- **Committed in:** 466feef

**3. Preview UX dead-end**
- **Issue:** Document page showed 3 questions + "5 more..." with no way to expand
- **Fix:** Removed preview entirely, kept clean stats + single CTA approach
- **Committed in:** 466feef
