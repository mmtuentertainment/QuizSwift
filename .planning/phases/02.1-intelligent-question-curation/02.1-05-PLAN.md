1. Imports katex, its CSS, and DOMPurify
2. Exports MathDisplay component with props: math (string), displayMode (boolean), className (string)
3. Uses katex.renderToString with trust: false for security
4. CRITICAL: Sanitizes KaTeX output with DOMPurify.sanitize() before rendering
5. Handles errors gracefully by showing escaped raw LaTeX
6. Exports convenience wrappers: InlineMath and BlockMath
7. Exports MathText component that parses $...$ and $$...$$ in strings

Key implementation pattern:

```typescript
import DOMPurify from 'dompurify';
import katex from 'katex';

// Render and sanitize
const rawHtml = katex.renderToString(math, { displayMode, trust: false });
const sanitizedHtml = DOMPurify.sanitize(rawHtml);
// Then use sanitizedHtml in the component
```

For escaping HTML in error fallback, use manual entity replacement:
```typescript
function escapeHtml(text: string): string {
  return text
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#039;');
}
```
