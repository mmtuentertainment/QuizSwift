## Decisions Made

1. **Sequential pass execution** - Each pass builds on previous context for holistic understanding
2. **2x question generation** - Generate double the requested count for selection flexibility
3. **Progress callback pattern** - Enables real-time UI feedback during long AI processing
4. **Timing statistics** - Captured per-pass timing and total tokens for monitoring
