## Security Implementation

**XSS Prevention:** All HTML rendering uses DOMPurify sanitization:

1. KaTeX generates HTML from LaTeX input
2. DOMPurify.sanitize() processes the HTML to remove any malicious content
3. Only sanitized HTML is rendered

Code pattern in math-display.tsx:
```typescript
const rawHtml = katex.renderToString(math, { trust: false });
const sanitizedHtml = DOMPurify.sanitize(rawHtml);
// sanitizedHtml is safe for rendering
```

## Decisions Made

1. **tldraw 4.x export API:** Used `editor.getSvgString()` + `getSvgAsImage()` instead of removed `exportToBlob`
2. **Security-first rendering:** All KaTeX HTML passes through DOMPurify.sanitize() before rendering
